One iPhone widget for PocketDex, Haru, Cozy Island and Cairn

Your partner and habits, today's Haru scene, your island garden and your live coding sessions, side by side on the home screen. Apps send a change about a second after it happens; the live view shows it at once, and the widget catches up when iOS next redraws it.

Step 1

Make your widget code

The code is a private address that links your apps to your widget. Keep it to yourself: anyone who has it can read the summary your apps send.

Step 2

Link the apps

Pairing this browser already covers the three web apps opened in it. Open each one once so it sends its first update. For another device, or an app you added to the home screen, open it with the link below or paste the code in its settings.

  • Open PocketDex (code field: More, Trainer, iPhone widget)
  • Open Haru (code field: Settings, iPhone widget)
  • Open Cozy Island (pairs through the link)
  • Cairn runs on your PC: in a terminal there, run cairn widget pair jw-… not for Scriptable (the Cairn desktop app then sends your live sessions within seconds of a change)

Step 3

Add the widget on the iPhone

  1. Install Scriptable from the App Store. It is free.
  2. Open this page on the iPhone, enter the same code above, then tap Copy widget script.
  3. In Scriptable tap +, paste, and name the script Trio. Run it once to see a preview.
  4. Hold an empty spot on the home screen, tap Edit then Add Widget, choose Scriptable and a size.
  5. Hold the new widget, tap Edit Widget and set Script to Trio.
  6. For the instant view: open the live view on the iPhone, tap Share, then Add to Home Screen. Tapping the widget opens it too.

Sizes: medium shows all four as a 2 by 2 grid, large shows four rows with more detail. Small shows one app: type pocketdex, haru, cozy or cairn in the widget's Parameter field, or leave it empty to show whichever has a timer running. Lock-screen sizes work too.

Good to know

  • How live it is. Apps send a change about a second after it happens (then at most every 20 seconds per app; Cairn checks every 3 seconds). The live view shows it the moment it arrives. The home-screen widget can't be pushed: iOS decides when it redraws, usually every 5 to 15 minutes, though its countdown timers tick every second.
  • What is sent. Names, counts and timer end times only: partner and level, Pokédex and habit counts, the Haru weather scene and day counts, island season, garden bloom times and totals. Cairn sends session titles, step kinds (passed, failed, committed) and counts, never log text or files. No diary text, photos or place names.
  • Where it goes. Through ntfy.sh, a free public relay that keeps a message for about 12 hours. The widget keeps the last update it saw, so it does not go blank after that.
  • Turning it off. Unpair here or clear the code in an app and nothing more is sent from that browser. Make a new code if the old one was shared by mistake.
